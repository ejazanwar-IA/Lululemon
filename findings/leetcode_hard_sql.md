## Section D — How to Refresh This List

```bash
curl -s 'https://leetcode.com/api/problems/database/' \
  -H 'User-Agent: Mozilla/5.0' | python3 -c "
import json, sys
data = json.load(sys.stdin)
hards = [(q['stat']['frontend_question_id'], q['stat']['question__title'],
          q['stat']['question__title_slug'])
         for q in data['stat_status_pairs']
         if q['difficulty']['level'] == 3]
hards.sort(key=lambda x: x[0])
print(f'Total Hard: {len(hards)}')
for fid, title, slug in hards:
    print(f'{fid}. {title}  https://leetcode.com/problems/{slug}/')
"
```

`difficulty.level` mapping in the LeetCode API: **1 = Easy, 2 = Medium, 3 = Hard.**
